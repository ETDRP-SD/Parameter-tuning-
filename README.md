# Parameter Tuning Data for Comparative Algorithms

This directory provides the parameter-tuning data used to configure the  
three baseline algorithms in the comparative experiments.

## Purpose

The parameter-tuning records are provided to improve the transparency  
and reproducibility of the computational experiments. For each  
algorithm, candidate parameter values were evaluated and the resulting  
solution quality was recorded using **Δ%**.

A lower Δ% represents better solution quality.
